Sentiment analysis classifies text as positive or negative. The model below (Xenova/distilbert-base-uncased-finetuned-sst-2-english) runs entirely in your browser — no data leaves your machine.

What's happening: The ONNX-exported DistilBERT model is loaded into WebGPU memory. Your text is tokenized client-side, fed through the model, and softmax scores are returned — all in JavaScript.

Semantic similarity uses embeddings to measure how close two texts are in meaning, not just word overlap. The model (Xenova/all-MiniLM-L6-v2) encodes each sentence into a 384-dimensional vector, then we compute cosine similarity.

What's happening: Each sentence is tokenized and passed through a BERT-family model. The [CLS] token embedding is extracted, normalized, and the dot product gives us a similarity score from 0 to 1.

Zero-shot classification assigns labels to text without task-specific training. You provide candidate labels and the model (Xenova/mobilebert-uncased-mnli) scores each one using natural language inference — deciding if the text "entails" each label.

What's happening: For each label, the model evaluates the hypothesis "This text is about [label]" against your input as the premise. The entailment scores are softmaxed into probabilities.

Text generation with a small language model running locally. This uses onnx-community/Qwen3-0.6B-ONNX — a 0.6B parameter model, quantized to 4-bit, loaded entirely into your browser's WebGPU memory.

What's happening: The quantized model weights are fetched from Hugging Face Hub, cached in browser storage, then inference runs on your GPU via WebGPU. Token generation is autoregressive — each token is produced one at a time. This is genuinely a language model running on your hardware.
